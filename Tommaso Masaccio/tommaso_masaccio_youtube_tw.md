# 馬薩喬：讓繪畫重新站在地面上

## A. 影片核心敘事
馬薩喬在短暫生涯中，使宗教人物共享可信的地面、光線與建築空間。影片從同一座禮拜堂兩組亞當與夏娃的對照出發，穿過壁畫、祭壇畫與《聖三位一體》，教觀眾用腳步、陰影、手勢與透視讀畫。

## B. 建議影片標題
1. 馬薩喬：讓繪畫重新站在地面上
2. 一幅壁畫，為什麼改變了人物的重量？
3. 亞當與夏娃走出樂園：馬薩喬的繪畫革命

## C. 影片架構
1. 一個會投下影子的身體
2. 佛羅倫斯的新視覺語言
3. 三個時刻，同一個空間
4. 被逐的重量與城市中的神蹟
5. 金地祭壇畫中的文藝復興身體

### Segment 1 — 一個會投下影子的身體

**Purpose / 段落功能:** 以作品與觀看問題吸引觀眾。

**Key Message / 核心訊息:** 一個會投下影子的身體：用畫面證明人物、光線和空間的關係。

**Content / 內容**
先讓觀眾看畫，不先報生卒年。馬索利諾的亞當與夏娃姿態優雅；馬薩喬筆下的兩人卻踏出樂園，亞當遮臉，夏娃哭喊。並排畫面之後放大腳步、身體與陰影，提出影片問題：年輕畫家如何讓神聖人物彷彿與我們共處同一世界？快速閃過《納稅銀》的群像和《聖三位一體》的拱頂，留下三個觀看線索：腳站在哪裡、光從哪裡來、空間能否走進去。

### Segment 2 — 佛羅倫斯的新視覺語言

**Purpose / 段落功能:** 推進主線並建立可見的藝術史觀察。

**Key Message / 核心訊息:** 佛羅倫斯的新視覺語言：用畫面證明人物、光線和空間的關係。

**Content / 內容**
馬薩喬1401年出生，至1422年已在佛羅倫斯以畫家身分活動；他的學徒經歷仍無確切文獻。《聖朱維納爾三聯畫》保留金地與尖拱，卻讓聖母的身體和寶座顯得有體積、有深度。不要把它說成「首次發明透視」。佛羅倫斯的建築、雕塑實驗提供理解背景，但他與布魯內萊斯基、多納太羅直接合作並無文獻可證。接著用《聖安妮與聖母子》介紹合作夥伴馬索利諾：放大厚實的聖母子，再移向周圍柔和的人物，看兩種畫法如何共存。

### Segment 3 — 三個時刻，同一個空間

**Purpose / 段落功能:** 推進主線並建立可見的藝術史觀察。

**Key Message / 核心訊息:** 三個時刻，同一個空間：用畫面證明人物、光線和空間的關係。

**Content / 內容**
《納稅銀》是影片的視覺核心。先找到基督與使徒，再依手勢追蹤事件：稅吏要求繳稅、基督指示彼得、彼得到左側魚口取錢、最後在右側付款。畫面把三個時刻安排在同一個連續空間，鏡頭可順敘事左右移動。接著看退向遠方的建築、群山、人物共用的地面和光線。這是《馬太福音》17:24–27的聖殿稅故事，不能與「凱撒的歸凱撒」混同。短暫並看馬索利諾的城市神蹟場景，讓觀眾感受合作現場的不同畫法。

### Segment 5 — 金地祭壇畫中的文藝復興身體

**Purpose / 段落功能:** 推進主線並建立可見的藝術史觀察。

**Key Message / 核心訊息:** 金地祭壇畫中的文藝復興身體：用畫面證明人物、光線和空間的關係。

**Content / 內容**
1426年的比薩多聯祭壇畫把故事轉到木板畫。原作後來拆散，面板分藏多館。先看倫敦的《聖母子》：聖嬰吃葡萄、寶座後退、聖母投下陰影、光環隨頭部角度傾斜；金地仍在，革新就在傳統格式內發生。接著看那不勒斯《十字架刑》，留意原先較高的展示位置與抹大拉張開雙臂的悲痛。柏林《三王來朝》雖狹長，隊伍與馬匹遮擋仍帶出深度。若以簡圖示意整座祭壇的相對位置，應註明完整配置是後來的重建。

### Segment 6 — 牆壁裡的禮拜堂

**Purpose / 段落功能:** 推進主線並建立可見的藝術史觀察。

**Key Message / 核心訊息:** 牆壁裡的禮拜堂：用畫面證明人物、光線和空間的關係。

**Content / 內容**
在新聖母大殿，《聖三位一體》像打開教堂牆壁，露出深處的小禮拜堂。先呈現全畫，再沿格狀拱頂與柱線走向接近觀者視線高度的消失點。指出聖父、被釘十架的基督、鴿子形聖靈、聖母、聖約翰和跪姿委託人。聖母的手勢引導視線，鏡頭最後向下到骷髏與死亡警語，再由下往上回看救贖意涵。布魯內萊斯基直接參與設計沒有文獻證據；壁畫也曾被遮蔽、搬移，骷髏部分直到1952年才重新發現。

### Segment 7 — 短暫生涯，長久的影響

**Purpose / 段落功能:** 推進主線並建立可見的藝術史觀察。

**Key Message / 核心訊息:** 短暫生涯，長久的影響：用畫面證明人物、光線和空間的關係。

**Content / 內容**
馬薩喬生涯末期前往羅馬。倫敦國家美術館將《聖耶柔米與施洗者聖約翰》歸於他，標約1428–1429年；其藝術家介紹又把卒年寫作1428/9並附問號。死亡確切日期與原因不明，毒殺或瘟疫均不能說成定論。回到佛羅倫斯，布蘭卡契禮拜堂成為後輩研究身體、手勢和群像的場所，菲利皮諾・利皮數十年後接續部分壁畫。重看《聖三位一體》和《納稅銀》：透視最有力量的時刻，是它幫助觀者理解人物正在經歷什麼。

## G. 事實查核備註
- 《聖朱維納爾三聯畫》署1422年日期；早期空間實驗不應稱為史上第一次透視。
- 《聖安妮與聖母子》為合作作品，具體分工仍有研究判斷。
- 《納稅銀》是《馬太福音》17:24–27的聖殿稅，政治寓意並無單一定論。
- 《聖彼得治癒跛者與復活塔比塔》主要歸於馬索利諾，作比較素材，不列馬薩喬獨立作品。
- 比薩祭壇畫面板分散，完整配置為重建；霍恩博物館《聖朱利亞諾的故事》屬另一委託。
- 《聖三位一體》約1425–1427，教堂採約1425–1426；布魯內萊斯基直接協助無文獻證據。
- 倫敦國家美術館將卒年標為1428/9?，晚期《聖耶柔米與施洗者聖約翰》標約1428–29；死因未知。
