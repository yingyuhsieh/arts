# 讓・傅凱 Jean Fouquet｜YouTube 影片內容企劃（繁中）

## A. 影片核心敘事

一位國王、一名財政官、一本拆散的祈禱書：傅凱把十五世紀法國的權力與信仰畫成可被觀看的形象。影片從查理七世的紅色肖像出發，走進分藏柏林和安特衛普的《默倫雙聯畫》，再翻閱時禱書及王國編年史。收束於一個問題：當畫作與書頁分散各地，我們如何重新看見它們原來的關係？

## B. 建議標題

1. **沒有王冠的國王：讓・傅凱如何畫出法國的權力？**

3. **從宮廷肖像到祈禱書：讓・傅凱的十五世紀法國**

## D. 詳細段落企劃

### 1. 開場：沒有王冠的國王
- **目的：** 以反直覺的視覺細節引出王權形象。
- **核心訊息：** 查理七世不靠王冠，仍以紅衣、帷幕與穩定的體積占據畫面。
- **內容：** 先只看紅色布料，再揭露國王的臉。觀眾也許期待皇冠或寶座，但傅凱把權威放在人物的凝重姿態與凝視之中。這幅畫屬於戰後逐步重建的法國；我們將看見同一位畫家如何為王室、官員與祈禱者塑造身分。不要把畫面直接當作某一政治事件的現場紀錄。
- **作品／人物／地點：** 《查理七世肖像》，羅浮宮；查理七世。
- **視覺素材：** A01 全幅、紅衣細節、臉部、兩側帷幕（4 個鏡頭）。
- **資料頁：** https://collections.louvre.fr/ark:/53355/cl010064847
- **圖片直連／權利：** 見 E 表 A01。
- **建議順序：** 紅色局部 → 臉部 → 拉遠至全畫 → 標題。

### 2. 義大利之行與宮廷肖像
- **目的：** 建立跨地域經驗與肖像手法。
- **核心訊息：** 傅凱曾在羅馬為教宗作畫；現存肖像顯示他如何結合細緻觀察與幾何秩序。
- **內容：** 1440 年代傅凱赴義大利，為教宗恩仁四世繪製的肖像如今失傳，因此不能用後世圖片假裝是原作。回到法國的作品中，查理七世的肉身感與朱韋內爾・德・于爾桑的祈禱姿態，分別呈現國王及高官的威儀。義大利經驗有助於理解他的空間安排，但不能將每個形式細節都歸因於一次旅行。
- **作品／人物／地點：** 失傳的《教宗恩仁四世肖像》；A01、A02；羅馬、圖爾。
- **視覺素材：** A01 全幅、A02 全幅、A02 雙手與背景細節（4）。
- **資料頁：** https://arts-graphiques.louvre.fr/detail/artistes/0/1016-FOUQUET-Jean ; https://collections.louvre.fr/ark:/53355/cl010064846
- **圖片直連／權利：** 見 E 表。
- **建議順序：** 地名字幕 → A01 與 A02 並列 → A02 細節。

### 3. 左翼：委託人進入聖像
- **目的：** 說明私人贊助與宗教圖像的關係。
- **核心訊息：** 舍瓦利耶跪在聖史提反旁，讓私人身分進入莊嚴的祭壇畫。
- **內容：** 《默倫雙聯畫》的左翼現藏柏林。財政官艾蒂安・舍瓦利耶在自己的守護聖人聖史提反引領下跪向另一側；聖人手持與殉道相關的石塊。鏡頭先讓觀眾讀懂兩人的姿態，再把視線帶到畫外，提醒大家：這幅畫原本需要與另一翼一起觀看。分離後的單幅照片仍保留人物，卻失去原來的視線交流。
- **作品／人物／地點：** A03；柏林繪畫館；舍瓦利耶、聖史提反。
- **視覺素材：** A03 全幅、跪姿、聖人與石塊、朝右翼的視線（4）。
- **資料頁：** https://search.smb.museum/object/obj-865553?page=2&sammlungen=Gem%C3%A4ldegalerie
- **圖片直連／權利：** 見 E 表 A03。
- **建議順序：** 人物局部 → 全幅 → 空白側延伸 → 右翼切入。

### 4. 右翼：聖母、天使與自畫像
- **目的：** 解讀雙聯畫最鮮明的視覺張力及畫家署名。
- **核心訊息：** 紅藍天使包圍白色聖母；原框上的琺瑯圓章又讓畫家本人進入作品。
- **內容：** 右翼現藏安特衛普。幾乎雕塑般的聖母與聖嬰，面對左翼的祈禱者；鮮紅與深藍的天使使畫面格外不真實。露出的乳房可放在哺乳聖母的圖像傳統中理解。聖母被認作國王情婦阿涅絲・索蕾爾的說法廣為流傳，卻不能當成已證實的肖像身分。原框上還有傅凱的琺瑯自畫像圓章，如今藏於羅浮宮；勿將圓章誤說成畫板中央的一部分。
- **作品／人物／地點：** A04、A05；安特衛普、巴黎。
- **視覺素材：** A04 全幅、紅藍天使、聖母與聖嬰、A05 圓章（4）。
- **資料頁：** https://kmska.be/nl/meesterwerk/madonna-omringd-door-serafijnen-en-cherubijnen ; https://collections.louvre.fr/ark:/53355/cl010115375
- **圖片直連／權利：** 見 E 表。
- **建議順序：** 雙翼並置 → 右翼全幅 → 天使細節 → 圓章。

### 5. 被拆散的祈禱書
- **目的：** 從板畫轉入書頁與私人閱讀。
- **核心訊息：** 傅凱在微小頁面中創造宏大空間；拆散的書本仍需按原用途理解。
- **內容：** 為舍瓦利耶製作的《時禱書》原是供個人祈禱的連續書籍，後來被拆散；尚蒂伊孔代博物館保存四十頁，並非原書總頁數。選一張委託人與守護聖人同框的彩飾，和祭壇畫左翼相互呼應。接著簡述《西蒙・德・瓦里時禱書》有多位畫家參與，不能把整本書每一頁都歸傅凱。書頁的尺寸改變，塑造人物、建築和光的企圖卻一樣鮮明。
- **作品／人物／地點：** A06、A07；尚蒂伊、蓋蒂博物館與荷蘭國家圖書館。
- **視覺素材：** A06 全頁、人物、建築空間、A07 館藏頁（4）。
- **資料頁：** https://chateaudechantilly.fr/categ-collection/manuscrits/les-heures-detienne-chevalier-par-jean-fouquet/ ; https://www.getty.edu/art/collection/object/103RW9
- **圖片直連／權利：** 見 E 表；A07 待核影像授權。
- **建議順序：** 翻頁動作 → A06 全頁及細節 → 館藏分散地圖 → A07。

### 6. 將歷史畫成秩序
- **目的：** 從私人祈禱走向王國的公共敘事。
- **核心訊息：** 編年史與騎士團彩飾把權力安排成可讀的隊列與儀式。
- **內容：** 在《法蘭西大編年史》的宴會場景，畫家描繪的是 1378 年查理五世款待皇帝查理四世的往事，作品本身則作於約 1455–1460 年；它是後來建構的歷史圖像，不是當場速寫。約 1470 年的聖米歇爾騎士團會議彩飾又讓路易十一置於秩序井然的宮廷之中。兩張圖不只是「發生了什麼」，更在安排「王權應如何被看見」。
- **作品／人物／地點：** A08、A09；法國國家圖書館。
- **視覺素材：** A08 全頁、宴席中央、A09 全頁、國王與騎士（4）。
- **資料頁：** https://classes.bnf.fr/fouquet/pages/scene.htm ; https://classes.bnf.fr/fouquet/grand/f129.htm
- **圖片直連／權利：** 見 E 表；A09 待核。
- **建議順序：** 1378 與 1455–60 雙日期字幕 → A08 → A09 → 隊列對照。

### 7. 肖像以外的哀悼與戰爭
- **目的：** 展示宗教情感及晚期敘事的尺度。
- **核心訊息：** 大幅祭壇畫與歷史戰鬥圖像擴展了傅凱的創作範圍，但歸屬須謹慎。
- **內容：** 努昂教堂的《哀悼基督》以群像、沉靜表情與橫向構圖帶來不同於宮廷肖像的情感；介紹時以「歸 attributed to 傅凱」表述。再看羅浮宮所藏通稱《坎尼會戰》的彩飾，整齊的軍隊與繁密細節把古代故事帶進十五世紀的視覺語言。手稿不同部分可能出自不同畫家，不能把裝飾邊框一概歸給傅凱。
- **作品／人物／地點：** A10、A11；努昂萊豐泰訥、羅浮宮。
- **視覺素材：** A10 全幅與人物細節、A11 全頁與軍隊細節（4）。
- **資料頁：** https://pop.culture.gouv.fr/notice/palissy/PM37000342 ; https://collections.louvre.fr/ark:/53355/cl020214911
- **圖片直連／權利：** 見 E 表；A11 待核。
- **建議順序：** A10 緩推 → 情緒停頓 → A11 快速橫移 → 全頁。

### 8. 結尾：重組傅凱的世界
- **目的：** 回扣作品分散與觀看方式。
- **核心訊息：** 畫板、圓章和書頁如今分藏各地；把關係放回一起，才更接近它們原先的觀看經驗。
- **內容：** 重新並置《默倫雙聯畫》兩翼和自畫像圓章，再切回時禱書的委託人與王國編年史。傅凱讓國王具有重量，讓贊助人出現在神聖世界，讓歷史成為排列精密的畫面。結尾請觀眾選一張最想放大觀看的細節，並以館藏連結引導深入閱讀；畫面需標示雙翼與圓章的現藏地，而非暗示它們仍在原框內。
- **作品／人物／地點：** A01、A03–A06、A08。
- **視覺素材：** 各圖再取一個不同裁切、雙翼與圓章分藏示意（6）。
- **資料頁：** https://www.smb.museum/en/museums-institutions/kulturforum/exhibitions/detail/jean-fouquet-the-melun-diptych/ ; https://chateaudechantilly.fr/categ-collection/manuscrits/les-heures-detienne-chevalier-par-jean-fouquet/
- **圖片直連／權利：** 見 E 表。
- **建議順序：** 雙翼並置 → 三館地名 → 書頁 → 國王肖像 → 結束提問。

## F. 尚缺視覺素材

- A02、A07、A09、A11 尚無已核可的原檔直連；剪輯前從館方頁面取得影像與使用條件，或改用已核對授權的替代圖。
- 恩仁四世肖像原作失傳；若使用後世摹本，需明示「後世摹本」及個別權利，不得當成傅凱原作。
- 雙翼與圓章的重組示意需明確標示為剪輯模擬；館藏地名卡與 1378／1455–60 日期卡可自行製作。

## G. 史實核對備註

1. 生卒年用約 1420 至 1478–1481，不給確切生日或卒年；羅馬委託的原作已失傳。來源：https://arts-graphiques.louvre.fr/detail/artistes/0/1016-FOUQUET-Jean
2. 《默倫雙聯畫》兩翼及原框圓章現分藏三地；雙翼定年各館可能不同，統稱約 1450 年代較穩妥。阿涅絲・索蕾爾身分未獲證實。來源：https://www.smb.museum/en/museums-institutions/kulturforum/exhibitions/detail/jean-fouquet-the-melun-diptych/ ; https://www.kmska.be/en/6-things-you-need-know-about-fouquets-madonna
3. 《舍瓦利耶時禱書》尚蒂伊保存四十頁，是原書拆散後的存世部分，不是全書原頁數。來源：https://chateaudechantilly.fr/categ-collection/manuscrits/les-heures-detienne-chevalier-par-jean-fouquet/
4. 《西蒙・德・瓦里時禱書》有多位畫家；選圖時逐頁核對歸屬。來源：https://www.getty.edu/art/collection/object/103RW9
5. 《大編年史》宴會敘述 1378 年事件，彩飾作於約 1455–60；《努昂哀悼基督》採「歸於傅凱」。來源：https://classes.bnf.fr/fouquet/pages/scene.htm ; https://pop.culture.gouv.fr/notice/palissy/PM37000342
6. 羅浮宮 RF 5271 的邊框涉及不同作者；不可將整張裝飾一概歸傅凱。來源：https://collections.louvre.fr/ark:/53355/cl020214911
