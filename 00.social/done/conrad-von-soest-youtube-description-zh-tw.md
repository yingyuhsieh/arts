一本祭壇畫裡幾乎看不見的幾個字母，為什麼能讓一位中世紀畫家的名字重新被看見？

這支影片從康拉德・馮・索斯特（Conrad von Soest）的作品出發，走進約 1400 年的國際哥德式世界：從 1403 年《維爾東根祭壇畫》如宗教劇場般展開的十三幕敘事，到約 1420 年《聖母祭壇》更安靜、更集中的情感表現。我們會仔細看他筆下流動的衣褶、金藍紅綠的華麗色彩、人物之間的距離與觸碰，也會看到聖經故事中竟然出現了當時生活裡的眼鏡、書本與日常照料。

故事最後回到《聖母之死》中的一個微小線索：1950 年，Rolf Fritz 注意到書頁上的殘缺字母「con..d」。結合城市檔案與其他證據，這個細節讓康拉德的名字再次變得清晰，也讓我們看見中世紀畫家如何逐漸從匿名工坊中浮現。

看哥德式祭壇畫，不一定要先用文藝復興的透視標準衡量它。試著看人物、衣褶、色彩、彼此距離與日常物件，最後再尋找畫家留下的名字。

訂閱頻道，一起用更容易理解的方式走進中世紀與歐洲藝術。
