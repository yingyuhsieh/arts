# 草間彌生：從童年幻覺到無限鏡屋

草間彌生把曾經威脅著要吞沒她的圖案，轉化成現代藝術中最鮮明、也最容易辨識的視覺語言之一。

1929年，草間彌生出生於日本長野縣松本市。她從小便經歷強烈的幻視：花朵、圓點與網紋彷彿會越過物體表面，蔓延到整個房間，甚至覆蓋她的身體。畫畫因此不只是興趣，而是她面對恐懼、維持生活的方式。此後七十多年，她把這種私人經驗轉化為繪畫、雕塑、行為、電影、公共藝術與沉浸式空間，最後邀請全世界走進她的視覺世界。

本集將透過作品追蹤這條漫長的創作路徑。我們從1951年《捕捉網》的密集線條與1952年《積聚》不斷繁殖的圓點開始，接著進入紐約，看她如何以巨幅《無限網》拒絕抽象表現主義英雄式的筆觸，改用重複、時間與身體勞動覆蓋畫布。

到了1960年代，重複開始逃離平面。《積聚一號》以手縫軟雕塑吞沒扶手椅；《聚合：一千艘船展》利用大量照片讓單一物件侵入整個房間；1965年的《無限鏡屋——陽具原野》則用鏡面讓有限物件看似無窮，並把觀眾一起帶進作品之中。

影片也將回顧她在1966年威尼斯雙年展場域進行的非官方介入《水仙花園》、反越戰行動與實驗電影《草間的自我消融》、返回日本後的低潮，以及1989年紐約回顧展與1993年正式代表日本重返威尼斯的歷史轉折。

後期的直島《南瓜》、《消融之屋》、《水上螢火蟲》、《充滿生命光輝》、《數百萬光年外的靈魂》、《愛正在呼喚》與《渴望永恆》更證明：無限鏡屋從來不是一套固定公式。草間彌生持續改寫它，用相似的鏡面與重複語言，探問恐懼、身分、愛、死亡、時間與宇宙。

她的藝術也留下了一個非常當代的矛盾：原本用來動搖單一自我、讓「我」逐漸消融的空間，後來卻成為全世界最熱門的自拍場景之一。當自己的影像被無限複製，我們究竟變得更加可見，還是逐漸消失在複本之中？

草間彌生沒有真正逃離那些曾要吞沒她的圖案。她把它們畫下、縫起、拍攝並反射，最後學會了指揮它們。
