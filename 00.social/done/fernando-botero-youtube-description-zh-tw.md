# 費爾南多・波特羅：圓潤的魔法

「我畫的不是胖，而是對體積的讚美。」費爾南多・波特羅的作品一眼就能辨認：巨大而圓潤的身體、縮小的五官與手腳、平靜的表情，以及一個連動物、樂器、水果、家具和整個房間都會膨脹的世界。

但波特羅並不只是「畫胖子」。他一生真正探索的是比例。透過放大外輪廓、縮小局部細節，他建立了一套獨特的尺度系統，讓體積可以轉化為歡樂、權力、諷刺、溫柔、悲傷、暴力與歷史記憶。

1932年，波特羅出生於哥倫比亞麥德林。少年時期，他曾進入鬥牛學校；競技場中的儀式、色彩、服裝、動物與危險，成為他一生反覆描繪的題材。1951年他在波哥大舉行首次個展，1952年獲哥倫比亞全國藝術家沙龍油畫第二獎。

歐洲之行改變了他的藝術尺度。在普拉多博物館，他研究委拉斯開茲與哥雅；在佛羅倫斯，他接觸喬托、皮耶羅・德拉・弗朗切斯卡與曼特尼亞。波特羅不是單純回到古典，而是把歐洲藝術史變成哥倫比亞與拉丁美洲藝術家可以重新編排的素材庫。

他著名的風格突破，來自一把曼陀林。當他把音孔畫得異常小，整把樂器突然變得巨大。巨大的外輪廓加上縮小細節，就能製造超乎尋常的體積；波特羅式形體不是醫學意義上的肥胖，而是經過精密設計的藝術尺度。

影片將細看《十二歲的蒙娜麗莎》、仿委拉斯開茲、哥雅、安格爾與拉斐爾的作品，以及《總統家庭》。制服、勳章、馬匹、姿勢與禮儀創造了權威，但波特羅扭曲的比例也讓我們看見公共權力背後的表演性與脆弱。

臺北《圓潤的魔法：費爾南多・波特羅》特展於2026年6月19日至10月11日在中正紀念堂一展廳展出，共有118件繪畫、水彩、素描與雕塑。波特羅的重量、壓縮空間與真實尺度，值得親自觀看。

波特羅的成就不是發明一種「胖人畫風」，而是建立一套能不斷改變倫理溫度的形式語言。同樣圓潤的身體，在嘉年華裡可以幽默，在肖像中可以莊嚴，在記憶裡可以脆弱，在虐待的記錄中則令人無法逃避。
