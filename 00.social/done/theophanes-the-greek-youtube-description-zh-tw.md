# 費奧凡・格列克：當神聖之光像閃電般擊中聖像

當神聖之光降臨時，它真的會安撫我們嗎？還是會像閃電一樣，突然擊中我們？

走進大諾夫哥羅德的伊里那街救世主變容教堂，你會看見深褐、赭紅、灰綠與白色筆觸組成的幽暗世界。顏料剝落、灰泥破碎，白線卻仍像閃電般劃過人物的額頭、眼窩、鼻樑與鬍鬚。這些壁畫的力量不在於它們保存完整，而在於歷經六百多年火災、戰爭、覆灰與損毀後，仍讓我們感覺到畫家下筆時的速度與力道。

一三七八年的伊里那街壁畫，是認識費奧凡・格列克最可靠的起點。諾夫哥羅德編年史記下畫家、教堂與年份；作品也仍在原本的建築空間裡。文獻、地點與現存材料能彼此對上的案例十分罕見。這不表示每一道留下來的筆觸都能單獨確認為費奧凡親筆——工程包含助手——但它確實是理解他藝術最牢靠的證據核心。

費奧凡大約出生於一三三〇至一三四〇年間的拜占庭文化圈。出生地、受訓經過與確切卒年都沒有可靠的同時代紀錄。約一四一五年，智者葉皮法尼在一封信中描寫他是一位博學、富有哲思的畫家：他不必一直盯著範本，能在鷹架上移動、和旁人交談，同時以驚人的速度作畫。這封信帶有讚頌性質，而且今天保存的是後世抄本，不是現場錄音；但它仍留下了中世紀文獻中少見的鮮明畫家形象——一位已把傳統內化到能夠自由作畫的大師。

要看懂費奧凡的白色高光，就必須放回十四世紀東正教的思想背景。靜禱主義與「非受造之光」的神學，提供了重要的觀看脈絡：那是基督在他泊山顯聖時所顯出的神聖能量。費奧凡筆下的高光、變容題材與苦修聖者，確實與這個思想世界高度相容；但沒有文獻證明他屬於某個特定的靜禱團體。白色提亮本來就是拜占庭繪畫的技法，費奧凡的獨特之處，是把逐層塑造形體的手段推到閃電、切痕與火花般的強度。那道光不像普通日光，反而像直接逼出人物內在狀態的力量。

請抬頭看伊里那街教堂穹頂的全能者基督。深色面部由少數明亮筆畫切開；眼睛、眉骨、鼻樑與鬍鬚都在有限色域裡被迅速界定。周圍的天使與銘文，讓這幅像不只是獨立的肖像，而是整座禮儀空間的中心。觀者一走進教堂，就進入那道凝視的範圍。它帶來的不只是審判感，也包含全能者基督傳統上的統御、教導、祈禱與救贖意義。

教堂裡的埃及馬卡里烏斯、柱頭苦行者與其他隱修聖者，則把肉身畫成靈性經驗的地形。枯槁的臉、深陷的皺褶與書寫般的線條，沒有把聖者畫得漂亮，卻讓苦修留下的時間痕跡充滿力量。先知以利亞同樣具有急迫感。費奧凡不追求柔和的自然主義，而是在聖像與禮儀的共同語法裡，把個人筆勢推到罕見的強度。

到了莫斯科，文獻把費奧凡與一三九五、一三九九及一四〇五年的工程連在一起，但那些早期壁畫大多已經消失。一四〇五年，編年史記載費奧凡、戈羅傑茨的普羅霍爾與年輕的安德烈・魯布廖夫共同參與早期聖母領報主教座堂工程。這是魯布廖夫的名字第一次出現在歷史文獻中。它證明了合作與可能的影響，卻沒有證明費奧凡正式收魯布廖夫為徒。

把兩人的視覺節奏放在一起比較很有啟發性：費奧凡常用斷裂線條、強烈高光與濃縮的嚴峻感，呈現與神聖相遇時的震撼；魯布廖夫則更常以連續曲線、平衡色彩與人物關係營造和諧。這不是兩種互相排斥的神學，而是同一傳統中兩種不同的精神節奏——一種是光突然降臨的衝擊，一種是相遇之後形成的共融。

幾件著名作品也必須小心說明。《頓河聖母》正面是聖母與聖嬰臉頰相貼的親密形象，背面是《聖母安息》。它傳統上歸於費奧凡或其藝術圈，不能當作有簽名的確定親筆。這份柔情提醒我們，費奧凡周邊的藝術並不只有乾枯、嚴厲的苦行者。特列季亞科夫畫廊的《基督變容》目前標示為「費奧凡圈子的畫家」之作，約作於十五世紀初；畫中的幾何光芒與倒地使徒，把壓倒性的神聖之光變成可見的動勢，但也不應直接稱為費奧凡本人確定的代表作。

費奧凡的遺產同樣是一場保存工程。據諾夫哥羅德博物館資料轉述，研究人員保存了約二十六萬片來自伊里那街教堂十四世紀壁畫層的碎片，分裝在約兩千三百個托盤裡。修復不是把過去刷得像全新，而是辨認每一小塊灰泥屬於哪位聖者、哪件衣褶或哪個建築區域，在不抹去歷史痕跡的前提下保存證據。

一四〇五年之後，費奧凡很快從史料中沉默。他可能在一四〇五至一四一五年間去世；常見的「約一四一〇年」只是後世估計。殘破牆面、編年史與一封書信，卻已足以讓他的藝術性格穿越巨大的歷史空白。

當白色筆觸穿過深色表面，我們看到的不只是十四世紀的技法，而是一個尖銳的問題：當真正的光降臨時，我們承受得住嗎？
