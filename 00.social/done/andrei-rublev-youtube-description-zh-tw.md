# 安德烈・魯布廖夫：一幅聖像如何成為俄羅斯的合一願景

安德烈・魯布廖夫沒有留下可信的肖像、日記、確切出生地與出生日期；他的名字只在少數中世紀編年史中短暫出現。然而，這位行蹤模糊的修士，後來卻成為俄羅斯最重要的聖像畫家，而他的《聖三位一體》更在六百多年來，持續塑造俄羅斯人對信仰、和平與合一的視覺想像。

本集將透過倖存的作品、文獻與材料證據，追查魯布廖夫的未解之謎。

他生活的時代籠罩在蒙古—韃靼勢力、戰爭、城市焚毀、政治衝突、瘟疫與火災之中。1408年，當軍事威脅再次逼近莫斯科地區時，魯布廖夫與丹尼爾・喬爾尼正在弗拉基米爾聖母安息主教座堂作畫。他們留下的《最後的審判》壁畫，沒有把重點放在恐怖與懲罰，而是以柔和面容、明亮色彩與平靜姿態，呈現恢復秩序與神聖慈悲的盼望，彷彿是對教堂外暴力世界的另一種回答。

關於他的生平，可靠線索非常有限。1405年的編年史第一次提到魯布廖夫，記載他與戈羅傑茨的普羅霍爾及拜占庭大師希臘人狄奧法內斯，共同裝飾莫斯科克里姆林宮聖母領報教堂的前身。史料無法證明狄奧法內斯是他的正式老師，卻足以顯示：魯布廖夫是在高度專業、多人合作的工作坊中成長，而非現代想像裡孤立創作的天才。

現代技術研究也讓這段傳奇變得更加複雜。茲韋尼哥羅德祈禱列中的《救世主》等著名聖像，長期被歸於魯布廖夫，但對底稿、顏料層與製作方法的分析，已重新提出個人作者歸屬的問題。部分名作可能來自更廣泛的拜占庭—俄羅斯藝術圈，或由多位畫家共同完成。

故事的核心是約作於1411年，或1425至1427年間的《聖三位一體》。魯布廖夫從亞伯拉罕款待三位訪客的《創世記》故事中，移除了亞伯拉罕、撒拉與大部分敘事情節，只留下三位天使安靜相對。他們微傾的頭部、翅膀與身體圍繞中央聖杯，形成連續的圓形節奏；逆透視則讓桌面向觀看者展開，把一段歷史故事轉化為對犧牲、團契與不以支配為前提之合一的沉思。

聖像本身的物質命運，也是故事的一部分。煙燻、變暗的塗層、金屬護罩、後世重繪、損傷與歷次修復，都改變了不同世代所看見的表面。1929年，作品進入特列季亞科夫畫廊；2022年曾因短期宗教展示引發保存疑慮，2023年俄羅斯政府決定將原作移交俄羅斯東正教會。2024年6月，它回到聖三一謝爾蓋修道院的聖三一主教座堂，安置於特製保護櫃中。

這次回歸重新引發一個困難問題：《聖三位一體》究竟是需要美術館環境保護的脆弱世界遺產，還是原本就為禮拜與祈禱而創作的神聖聖像？尊重活的信仰傳統與保存不可取代的六百年文物，都是正當責任，任何一方都不能讓另一方消失。

影片也將談到安德烈・塔可夫斯基1966年的電影《安德烈・魯布廖夫》。片中的沉默誓言、鑄鐘故事與許多人生情節，是填補史料空白的藝術創作，不能視為傳記事實；但電影確實讓魯布廖夫成為現代藝術良知的象徵——一位在暴力、審查與懷疑之中，仍然追尋美與信仰的創作者。

魯布廖夫最深遠的遺產，也許不是孤獨天才的神話，而是一種關係的視覺倫理。他筆下的人物彼此傾聽、共享空間，也拒絕讓任何一人支配整個畫面。六百年後，《聖三位一體》仍在追問：差異如何能保留差異，卻不走向彼此征服？
