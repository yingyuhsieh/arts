# 櫻桃樹 (The Cherry Tree / Le Cerisier)
**貝爾特·莫里索 (Berthe Morisot)**
## 畫作解析
《櫻桃樹》是莫里索1891年創作的油彩畫布，描繪了兩位年輕女性在櫻桃樹下摘取果實的場景——其中一位站在梯子上伸手摘櫻桃。畫面以莫里索晚期最自由的筆觸呈現——人物的輪廓幾乎溶解在周圍的綠色植物之中，陽光透過樹葉的效果以白色和金色的光斑暗示。這是莫里索晚期最大型和最具野心的戶外場景之一。現藏奧賽博物館（Musée d'Orsay, Paris）。
## 創作動機
莫里索晚期越來越專注於戶外的花園場景——梅齊（Mézy）鄉間住所的花園成為她最後幾年的主要創作場所。
