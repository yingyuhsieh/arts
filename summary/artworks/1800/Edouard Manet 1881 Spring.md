# 春天 (Spring)
**愛德華·馬奈 (Édouard Manet)**

## 畫作解析

《春天》是馬奈於一八八一年完成的油畫作品，描繪了一位年輕女子置身於繁花盛開的花園之中。畫面中的女子身穿一件圖案繁複的碎花連衣裙，頭戴裝飾著鮮花的時尚帽子，手中撐著一把陽傘。她的面容清麗動人，膚色白皙，嘴唇微啟，目光溫柔地望向觀眾，整個人散發出一種青春洋溢的生命活力。她的身後是一片濃密的灌木叢和盛開的花朵，綠色的枝葉和五彩繽紛的花瓣將她環繞其中，彷彿她本身就是這個春天花園中最美的一朵花。

馬奈在這幅作品中展現了他晚期風格的諸多特徵。筆觸變得更加輕快和流暢，色彩也比他早期的作品更加明亮和豐富。女子衣裙上的碎花圖案以快速而精準的筆觸描繪，每一朵小花都帶著一種即興般的生動感，這種處理方式與印象派的技法已經非常接近。背景中的植物則以更為鬆散的筆觸來表現，綠色的深淺變化和花朵的點點色斑交織在一起，營造出一種光影搖曳的戶外氛圍。整幅畫的色調以綠色和花卉的粉色、黃色為主，配以女子衣裙上的各種暖色調圖案，呈現出一種春日花園般的明媚和溫暖。

這幅作品原本是馬奈計劃中四季系列的第一幅，他打算以四位不同的女性來象徵春夏秋冬四個季節。然而由於健康狀況的急劇惡化，馬奈最終只完成了《春天》和《秋天》兩幅，另外兩幅未能實現。這個未完成的系列計劃使得《春天》在馬奈的作品中具有了一層額外的感傷意味——它既是對生命之美的熱情歌頌，也是一位生命即將走到盡頭的藝術家對青春和活力的最後眷戀。
