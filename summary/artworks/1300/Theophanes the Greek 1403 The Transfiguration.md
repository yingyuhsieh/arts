# 基督變容聖像 (The Transfiguration / Преображение)
**費奧凡·格列克 (Theophanes the Greek)（傳統歸屬）**

## 畫作解析

基督變容聖像（The Transfiguration / Преображение），約創作於一四零三年前後，是傳統上歸屬於費奧凡·格列克或其工作室的重要木板聖像畫。這幅以蛋彩畫（egg tempera）繪製於木板上的聖像，尺寸約一百八十四乘一百三十四公分，是一幅規模宏大的祭壇聖像，現收藏於莫斯科國立特列季亞科夫畫廊（State Tretyakov Gallery）。

畫面的主題取自《新約聖經》中的「基督變容」（Transfiguration）場景——《馬太福音》十七章記載，耶穌帶領彼得、雅各和約翰三位門徒上了一座高山（傳統上被認為是他泊山 / Mount Tabor），在那裡他的面容「如太陽般發光」，衣袍「白如光明」，摩西和以利亞顯現在他身旁。這一場景在東正教神學中具有核心地位——它被視為「非受造之光」（Uncreated Light / нетварный свет）在人間的直接顯現，是靜修主義（Hesychasm）神學的聖經原型。

畫面的構圖被精確地分為上下兩個區域，以此表達天上與地上、神聖與人間的對比。在上半部分，基督身著純白的袍服，站在山頂的中央，周圍環繞著銳利的幾何形光芒——那些從基督身體放射而出的白色星芒呈現出一種近乎水晶體般的幾何結構，代表著「非受造之光」的不可抗拒的超越性力量。這種光芒的處理方式極為獨特——它不是柔和的、漫射的自然光，而是銳利的、定向的、幾乎具有物理衝擊力的神聖能量。在基督兩側，舊約先知摩西（手持律法石板）和以利亞浮現在雲端之中，他們的身姿向基督微微傾斜，表達對神子的敬拜。

在下半部分，三位門徒在光芒的衝擊下倒地不起——他們的身體呈現出極度動態的姿勢：彼得跪地以手遮面，試圖抵擋令人目眩的光輝；雅各俯臥在地，身體因衝擊波而扭曲翻轉；約翰仰面跌倒，衣褶在光芒的衝擊下如旗幟般翻飛。這種對門徒身體的戲劇性處理，被評論者形容為「如同被光芒擊倒的布偶」（strewn about like rag dolls），充分展現了費奧凡式的表現主義張力——人類的肉身在面對神聖之光時的脆弱與無助。

在色彩處理上，這幅聖像展現了與諾夫哥羅德壁畫不同的色彩豐富度。基督的白袍以純淨的白色繪就，與周圍的金色光芒和深色的山岩形成強烈的明暗對比。摩西和以利亞的衣袍分別使用了橄欖綠色和暖棕色，三位門徒的衣袍則使用了更加鮮艷的藍色、紅色和綠色。金箔背景以拜占庭傳統的方式處理，象徵著超越時間的永恆空間。

在蛋彩畫的技法層面，這幅聖像的木板準備遵循了拜占庭的標準程序：多層石膏底層（levkas）被塗在乾燥的木板上，精心打磨後形成光滑的繪畫表面。蛋彩顏料以極薄的色層逐步疊加——這種技法使得色彩呈現出透明而發光的質感。白色高光的施加是整幅畫面的精神焦點——它們以精準而迅捷的筆觸完成，呈現出費奧凡標誌性的銳利風格。

## 創作動機

基督變容作為繪畫題材，在東正教藝術傳統中具有特殊而崇高的地位。與西方基督教藝術更多關注基督的受難和復活不同，東正教神學特別強調基督的「變容」——因為這一事件被視為神聖之光在人間最直接、最完整的顯現。十四世紀的靜修主義運動更將變容提升到了教義的核心位置：格列高利·帕拉瑪斯（Gregory Palamas）教導說，他泊山上的光芒不是受造的自然光，而是上帝本身的「非受造能量」——修行者通過持續的靜默祈禱和精神淨化，可以在此生中直接經驗到這種光芒。

費奧凡（或其工作室）創作這幅基督變容聖像，正是在這一神學背景下進行的。畫面中那些銳利的幾何形光芒——那些從基督身體放射而出的白色星芒——不是裝飾性的元素，而是對「非受造之光」的嚴肅的神學視覺化。門徒們被光芒擊倒的戲劇性場景，則表達了一個核心的神學觀點：人類的肉身在面對上帝的完全顯現時，是脆弱的、不堪承受的——唯有通過靈性的轉化，人才能真正「看見」並承受神聖之光。

這幅聖像可能是為某座教堂的聖像屏而創作的——其大型尺寸（近兩米高）暗示它被設計為安放在教堂內的醒目位置，作為信徒們禮拜和冥想的焦點。在東正教的禮拜傳統中，聖像不僅僅是裝飾性的藝術品，更是「神聖之窗」——信徒通過聖像的凝視，得以瞥見超越物質世界的神聖現實。

## 收藏故事

基督變容聖像的早期收藏歷史並不完全清楚。根據學者的推斷，這幅聖像可能原本安置在莫斯科或其附近的某座教堂之中——其大型尺寸和精湛的藝術水準暗示它是為一個重要的宗教場所而創作的。有學者推測它可能來自佩列斯拉夫爾-扎列斯基（Pereslavl-Zalessky）的救世主變容大教堂——這座教堂以「變容」為名，與聖像的主題相吻合。

在蘇聯時代的宗教藝術品國有化運動中，這幅聖像被轉移至莫斯科國立特列季亞科夫畫廊。作為俄羅斯中世紀藝術的重要收藏品之一，它被安置在畫廊專門的古俄羅斯藝術展廳中，與頓河聖母像、魯布廖夫的《三位一體》等傑作共同展出。

今天，這幅聖像被認為是靜修主義「光之神學」在視覺藝術中最完美的詮釋之一。美國學者瑪麗·伊麗莎白·波德萊斯（Mary Elizabeth Podles）在學術期刊《觸石》（Touchstone）上撰文指出，這幅聖像中「基督的幾何形光芒的驚人美感，與被光芒擊倒的門徒們的有序混亂形成了精妙的平衡」——它以視覺的方式呈現了一個深刻的神學悖論：神聖之光既是美的源泉，也是令人畏懼的力量。

特列季亞科夫畫廊對這幅六百餘年歷史的蛋彩畫實施了嚴格的保存措施——恆溫恆濕的展示環境、防紫外線的特殊燈光、定期的狀態監測——以確保這件珍貴的文物能夠繼續為後世的觀者傳遞費奧凡（或其工作室）所捕捉的那道超越時間的神聖光芒。
