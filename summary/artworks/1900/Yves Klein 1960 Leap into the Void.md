# 躍入虛空 (Leap into the Void / Le Saut dans le vide)
**伊夫·克萊因 (Yves Klein)**
## 畫作解析
《躍入虛空》是克萊因1960年創作的攝影作品——顯示他從巴黎郊區豐特奈-奧羅斯一棟建築的屋頂上縱身跳入空中，雙臂張開如鳥翼，下方是空曠的人行道。實際上是兩張底片的合成——一張有朋友用帆布接住他，另一張無帆布的街景。克萊因製作了一份仿報紙在巴黎報攤發行。這是藝術史上最著名的「偽紀錄」攝影作品——它模糊了現實與虛構、藝術與生活、可能與不可能之間的界限。現藏大都會藝術博物館（Met, New York）等多個機構（照片版本）。
## 創作動機
克萊因試圖以「飛翔」的姿態象徵藝術家超越物質限制的精神自由。
## 收藏故事
照片版本分藏多個博物館。仿報紙《星期日》成為了藝術收藏品。
