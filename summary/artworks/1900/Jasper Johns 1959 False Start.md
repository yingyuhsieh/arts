# 錯誤的開始 (False Start)
**賈斯培·瓊斯 (Jasper Johns)**

## 畫作解析

《錯誤的開始》（False Start）是賈斯培·瓊斯於1959年創作的油畫，以油彩繪於畫布上，尺寸約為170.8 × 137.2公分。畫面由鮮豔的色塊和手寫的色彩名稱（如「RED」「BLUE」「ORANGE」）構成，但文字標示的色彩名稱與實際色塊的顏色系統性地不匹配——「RED」可能寫在藍色的區域上，「BLUE」可能出現在橙色的色塊中。這種語言與視覺之間的故意錯位，直接挑戰了觀者對符號系統可靠性的信任。我們是「看到」色彩還是「讀到」色彩？當語言和視覺給出矛盾的訊息時，我們應該相信哪一個？這些問題使《錯誤的開始》成為了瓊斯探索感知與認知之間關係最深刻的作品之一。

## 創作動機

1959年的瓊斯已經在《旗幟》和《靶心》系列中確立了自己的藝術方法——選擇預先存在的符號並迫使觀者重新審視它們。《錯誤的開始》將這一方法推向了更加抽象和概念化的領域——它不再依賴於一個具體的可辨識圖像（如國旗或靶心），而是直接處理「命名」與「感知」之間的根本矛盾。標題「False Start」（錯誤的開始）暗示了一種系統性的失誤——色彩標籤與色彩本身之間的錯位如同一場永遠無法正確「開始」的比賽。

## 收藏故事

《錯誤的開始》目前為私人收藏。這幅畫在拍賣市場上創下了驚人的價格——1988年以1,700萬美元售出，後於2006年以8,000萬美元的價格私下成交，使其成為當時在世藝術家作品中最昂貴的之一。
