# 無盡之柱 (Endless Column / Coloana fără sfârșit)

## 畫作解析
《無盡之柱》（Endless Column / Coloana fără sfârșit）是蒂爾古日烏三部曲的最終作品和高潮，1937年至1938年完成。這座高達29.35公尺（約96英尺）的紀念性鑄鐵雕塑由十五個半截錐形模組（加上頂部和底部各半個模組）疊加而成，向天空無限延伸——暗示著超越物質世界的精神上升。每一個模組以相同的韻律重複——如同音樂中的節拍——構成了一首以鐵鑄就的視覺詩歌。

布朗庫西從1920年代就開始探索「無盡之柱」的母題——最早的版本是橡木雕刻的小型作品。蒂爾古日烏的紀念性版本將這一概念推向了極致——它不再是一件可以放在工作室或博物館中的雕塑，而是一座矗立在天地之間的建築性標誌，直接與天空對話。

在三部曲的精神敘事中，《無盡之柱》象徵了犧牲者靈魂的永恆超越——從《沉默之桌》的塵世告別，經過《吻之門》的愛的過渡，最終在《無盡之柱》中實現了向天國的無限上升。

蒂爾古日烏三部曲紀念了第一次世界大戰中犧牲的羅馬尼亞士兵——特別是1916年保衛吉烏河渡口的戰鬥中陣亡的士兵。布朗庫西以他最具標誌性的三個母題——桌（沉默/死亡）、吻（愛/過渡）和柱（無限/超越）——構建了一個從死亡到永生的精神旅程。《無盡之柱》作為旅程的終點，將觀者的目光和精神從地面引向無限的天空。
