# 機器幻覺：無人監督 (Unsupervised — Machine Hallucinations — MoMA)

## 畫作解析

《無人監督》（Unsupervised — Machine Hallucinations — MoMA）是阿納多爾於2022年受紐約現代藝術博物館（MoMA）委託創作的大型AI生成式裝置。作品於2022年11月19日至2023年10月29日在MoMA大廳展出，展出期間吸引了近三百萬觀眾，被《華盛頓郵報》譽為「AI生成藝術的早期傑作」。

裝置的物理形態是一面高達二十四英尺（約7.3米）的巨大LED螢幕，安置在MoMA大廳的顯眼位置，面對著落地玻璃窗。窗外是曼哈頓第53街的繁忙城市風景——汽車、行人、摩天大樓的剪影——與螢幕上AI生成的不斷演化的抽象景觀形成了持續的視覺對話。藝術史的「記憶」（螢幕上的AI生成影像）與當下的「現實」（窗外的城市）在觀眾的視野中交織在一起，創造了一個介於過去與現在、虛擬與真實之間的模糊地帶。

從數據和技術的角度分析，阿納多爾將MoMA超過兩百年藝術收藏的公開元數據輸入AI系統。至關重要的是，他使用的不是收藏品的圖像，而是它們的元數據——標題、年代、藝術家、媒材、尺寸、風格分類等文字和數值信息。AI在這些純粹的抽象數據中自主發現模式和聯繫，然後生成不斷演化的視覺景觀——一種「如果AI閱讀了整個現代藝術史的目錄，它會想像出什麼」的實驗。

視覺效果上，《無人監督》呈現為不斷流動和變形的三維數據結構——柔軟的拓撲曲面在螢幕上翻卷，色彩如同油畫顏料在水中擴散般地融合和分離。有時，觀眾可以在抽象形態中隱約辨認出類似繪畫筆觸、雕塑質感或攝影光影的視覺元素——這些是AI從MoMA典藏的元數據中「學到」的藝術語言的痕跡。但這些辨認永遠是模糊的、轉瞬即逝的——AI生成的影像不是對任何具體作品的模仿，而是對整個現代藝術史的抽象「夢境」。

作品的一個獨特之處在於它的「活」——《無人監督》不是預先錄製的影像迴圈，而是AI系統持續運算、實時生成的。每一個瞬間的視覺形態都是獨一無二的，永不重複。這意味著即使觀眾在同一天的不同時間造訪，看到的也是完全不同的影像。大多數博物館觀眾通常在一件作品前停留不到二十秒，但《無人監督》的觀眾平均駐足超過三十分鐘——這個數字本身就是對作品催眠般吸引力的最有力證明。

## 創作動機

《無人監督》的標題本身就蘊含了豐富的意義。在機器學習的術語中，「無監督學習」（Unsupervised Learning）是一種AI在沒有人類提供的標籤或指導的情況下，自主在數據中發現結構和模式的方法。阿納多爾選擇這種特定的AI方法論，是因為它最接近於他所追求的「機器夢境」概念——讓AI自主地、不受人類引導地在數據中尋找意義。

在更廣泛的語境中，「無人監督」也暗示了一個引發深思的倫理和哲學問題：當AI脫離人類的直接控制和監督，自主進行「創作」時，會發生什麼？「作者」是誰——是設計了系統的人類藝術家，還是實際生成了影像的AI演算法？阿納多爾並不迴避這些問題——他將它們視為作品本身的一部分，邀請觀眾在欣賞視覺之美的同時，思考人類與機器在創造力領域的共存。

選擇MoMA作為這件作品的場域具有特殊的藝術史意義。MoMA是全球現代藝術最重要的殿堂，其收藏涵蓋了從後印象派到當代藝術的完整歷程。讓AI「閱讀」這部兩百年的視覺藝術史，然後「想像」從未存在的藝術——這不僅是一個技術實驗，更是對藝術創作本質的根本追問：藝術的未來是否可以由機器來「預言」？

## 收藏故事

《無人監督》的收藏故事本身就是一個藝術史的里程碑事件。2023年10月，展覽結束後，MoMA宣布將這件作品納入博物館的永久收藏。這一收藏通過科技企業家和數位藝術收藏家 Ryan Zurrer（通過其1OF1收藏）和 RFC Collection（由 Pablo Rodriguez-Fraile 和 Desiree Casoni 領導）的聯合捐贈實現。
