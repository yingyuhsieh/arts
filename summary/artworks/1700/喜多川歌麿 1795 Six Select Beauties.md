# 高名美人六花撰 (Six Select Beauties / Komei Bijin Rokkasen)

## 畫作解析

《高名美人六花撰》（高名美人六歌撰，Komei Bijin Rokkasen，又譯「著名美人六歌仙」）是喜多川歌麿於寬政七至八年（約1795-1796年）創作的六幅系列錦繪版畫，由大宮權九郎（Omiya Gonkuro）出版。這一系列以六位當時最知名的美女為描繪對象，最為獨特的藝術特徵是使用了「判じ繪」（hanji-e，字謎畫）來暗示每位女子的身份——這是歌麿為應對寬政改革中禁止標注美女姓名的法令而發明的巧妙迂迴策略。每幅為多色錦繪大判尺寸，約三十八乘二十五公分。

在構圖方面，《高名美人六花撰》延續了歌麿成熟期的大首繪風格，每幅聚焦於一位女性的半身肖像。然而，與歌麿其他系列不同的是，每幅作品的右上角都設置了一個小型裝飾框，框內繪有一組由各種物品組成的字謎圖案。這些字謎圖案與主體人物的肖像形成了有趣的圖像對話——一方面它是揭示人物身份的密碼，另一方面它本身也是一件精緻的微型靜物畫。字謎框的存在使每幅作品的構圖具有了「畫中有畫」的層次感，邀請觀者在欣賞美人肖像的同時參與一場智力遊戲。

色彩運用方面，歌麿在這一系列中展現了其色彩調配的精湛技藝。每位美女的和服色調都經過精心選擇，以反映其個人特色和社會身份。作為來自不同場所的名媛——有吉原的花魁、茶館的女侍、表演藝術家——她們的衣著風格各有千秋。花魁的和服使用了最為華麗的色彩組合和複雜的圖案，而茶館女侍的服裝則體現了「粹」（iki）審美——以深藍、墨綠等沉穩色調為主，搭配簡潔而富有品味的紋飾。背景處理相對簡潔，以突出人物的面部表情和服飾特色。

六位美女的描繪各具神韻。難波屋阿北（Naniwaya Okita）是淺草水茶屋的看板女侍，以其清純甜美的氣質聞名。歌麿捕捉了她端茶招待客人時的優雅姿態，面部表情中帶有一種天然去雕飾的親和力。高島屋阿久（Takashima Ohisa）是兩國煎餅店的看板女侍，歌麿筆下的她展現出另一種風格的美——更加嬌媚和世故。富本豐雛（Tomimoto Toyohina）是吉原玉村屋的藝妓，以演奏富本節三味線而聞名，她的肖像流露出藝術家特有的自信和優雅。扇屋花扇（Ogiya Hanaogi）是吉原最負盛名的花魁之一，歌麿描繪了她正在構思一封信件的沉思姿態——寫信筆沾在面頰上，目光深邃地注視著紙面。其他兩位美女的身份也各有特色，共同構成了一幅江戶時代「美女名人錄」的視覺圖譜。

字謎畫（hanji-e）的設計是這一系列最具創意的藝術元素。每位美女的姓名被拆解為多個音節，每個音節用一個或幾個物品的圖像來暗示。以花扇為例：扇子（ogi）、箭矢（ya）、花朵（hana）和另一把扇子（ogi）的組合，拼出了「Ogiya Hanaogi」（扇屋花扇）的讀音。這種視覺密碼的設計需要極高的語言巧思和圖像創意——設計者必須為每個音節找到一個可以用簡明圖像表現的同音詞，同時確保整組圖案在視覺上協調美觀。字謎畫的存在使這些版畫成為了一種互動式藝術品——觀者需要運用自己的文化知識和語言能力來「解碼」畫中的秘密。

在技法層面，歌麿對花扇寫信場景的描繪堪稱經典。他捕捉了花魁在文思泉湧之際的微妙表情——眉頭微微蹙起，顯示她正在斟酌用詞；嘴唇微微張開，似乎在默讀剛剛構思的句子；毛筆輕觸面頰，這個獨特的姿態暗示了深度的思考和創作的愉悅。這幅作品不僅展示了花魁的美貌，更揭示了她作為一位文學創作者的智慧和修養。

就象徵意義而言，系列名稱中的「六歌撰」（Rokkasen）直接引用了日本文學史上著名的「六歌仙」（Rokkasen）——即在原業平、小野小町、僧正遍昭等六位平安時代的傑出和歌詩人。歌麿將當代的六位美女比作古代的六位詩歌大師，這一類比既是對美女們的讚美，也暗含了對「美」與「才」之間關係的思考。在寬政改革的壓力下，這種文學典故的運用也是一種巧妙的自我保護——以古典文化的外衣來包裝對當代名媛的描繪，使作品獲得了一層文化正當性。

## 創作動機

《高名美人六花撰》的創作動機深植於寬政改革的政治壓力之下，是歌麿在藝術表達自由受到嚴重限制的環境中，以創造力對抗審查制度的傑出範例。

寬政改革（1787-1793年）由老中松平定信主導，其核心目標是整頓社會風俗、恢復儒學道德秩序。對於浮世繪出版業而言，改革帶來了多項嚴厲的限制：情色作品被全面禁止，奢侈品的使用受到管控，更關鍵的是，1793年的法令明確禁止在版畫上標注實際人物的姓名。這最後一項規定對美人畫產業造成了直接的打擊——美人畫的商業價值在很大程度上依賴於畫中人物的名人效應，如果觀者無法辨識畫中的美女是誰，版畫的吸引力和銷售力都將大幅下降。

面對這一挑戰，歌麿的回應既機智又大膽——他發明了字謎畫（hanji-e）系統，將美女的姓名編碼為一組看似無害的物品圖案。這一策略在法律的灰色地帶中巧妙地遊走——版畫上確實沒有直接標注任何姓名，但知情的觀者完全能夠通過解讀字謎來識別畫中人物。這種「貓捉老鼠」的遊戲不僅挑戰了審查制度的權威，更為版畫的觀賞體驗增添了一層互動性和趣味性。

歌麿在這一時期更換出版商也是一個值得注意的創作背景。蔦屋重三郎在1791年因出版山東京傳的違禁著作而受到嚴厲處罰，此後出版活動受到密切監控。歌麿轉而與大宮權九郎合作，可能部分原因是為了規避與蔦屋相關的政治風險，也可能是為了獲得更大的創作自由度。大宮作為一位相對較新的出版商，可能更願意冒險出版這種在審查邊緣遊走的作品。

從藝術發展的角度來看，《高名美人六花撰》代表了歌麿在大首繪美人畫領域持續深化的努力。在完成了對女性性格類型（《婦人相學十體》）和情感狀態（《歌撰戀之部》）的探索之後，歌麿在這一系列中將注意力轉向了「名人肖像」這一更加個人化的題材。每一幅作品都試圖捕捉特定個人的獨特魅力，而不僅僅是一種抽象的類型。這要求畫家在程式化的美人畫語言中注入更多的個體差異，是一項極具挑戰性的藝術任務。

系列名稱中對「六歌仙」典故的運用反映了歌麿對文學傳統的深厚素養。透過將當代美女與古代詩人並列，歌麿不僅為作品賦予了文化深度，更暗示了一種跨越時代的美學對話——古代的詩人以文字表達美，當代的美女以容貌體現美，而歌麿則以畫筆捕捉美。這種多層次的文化引用使《高名美人六花撰》超越了一般的商業版畫，成為一件融合了文學、藝術和社會評論的綜合性文化作品。
