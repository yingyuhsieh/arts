# 《古代羅馬的馬爾斯廣場》(Il Campo Marzio dell'Antica Roma)
**喬瓦尼·巴蒂斯塔·皮拉內西 (Giovanni Battista Piranesi)**

## 畫作解析

《古代羅馬的馬爾斯廣場》（Il Campo Marzio dell'Antica Roma）是皮拉內西於一七六二年出版的最具想像力和最具爭議性的作品之一。這部著作的核心是一幅巨大的蝕刻版畫平面圖——「古代馬爾斯廣場平面圖」（Ichnographia Campi Martii），以極度大膽的想像力「復原」了古羅馬馬爾斯廣場（Campus Martius）的建築群。這幅平面圖是皮拉內西所有作品中最具理論深度的一件，被現代建築理論家視為「紙上建築」（Paper Architecture）的開山之作。

馬爾斯廣場位於古羅馬城北部的台伯河彎道處，在共和時期是軍事訓練場和市民集會場所，在帝國時期則逐漸發展為羅馬最繁華的城市區域，遍布劇場、浴場、神廟、柱廊和紀念碑。皮拉內西在繪製這幅平面圖時，以古代文獻記載和三世紀的塞維魯大理石城市地圖（Forma Urbis Romae）殘片為出發點，但他走得遠比任何考古學家更遠——在已知遺跡的基礎上，他添加了大量出自純粹想像的巨型建築結構。

這幅平面圖呈現出令人眼花繚亂的密度和複雜性。無數的圓形劇場、多邊形神廟、巨型柱廊、幾何形廣場和複雜的軸線系統以近乎強迫症般的密度覆蓋了整個區域，形成了一個比任何真實城市都更加宏偉和有序的理想化空間。皮拉內西特意將這幅平面圖呈現為一塊彷彿從牆上取下的古代石板——邊緣殘破，表面佈滿裂紋，以金屬夾固定在牆上——暗示它是一件從古代流傳下來的「真實」文獻，而非一件現代創作。

從技術層面來看，這幅巨型蝕刻版畫的製作是一項令人驚嘆的工藝成就。平面圖由多塊銅版拼合印製，總面積極大。每一座建築都以精確的平面圖符號語言繪製，柱列、牆體、階梯和庭院的細節清晰可辨。皮拉內西在繪製過程中展現了他深厚的建築學修養——即使是虛構的建築，也在結構邏輯上是可信的。

## 創作動機

《古代羅馬的馬爾斯廣場》的創作動機是多層次的。在最直接的層面上，這是皮拉內西為古羅馬建築偉大性所做的又一次辯護——緊接在一七六一年的《論羅馬人的偉大與建築》之後出版，它以視覺證據補充了理論論述。通過展示一個密集而宏偉的古代城市空間，皮拉內西要向世人證明古羅馬的城市建設達到了何等驚人的規模和複雜程度。

然而，這部著作的深層意義遠超考古學和論戰的範疇。在這幅平面圖中，考古事實與建築幻想之間的界限被有意模糊——觀者永遠無法確定哪些建築是基於考古證據的合理推測，哪些是出自皮拉內西純粹的想像。這種刻意的模糊性使這幅平面圖超越了考古復原圖的範疇，成為一件獨立的藝術和建築創造。

皮拉內西的這一做法引發了截然對立的評價。批評者（如同時代的一些考古學家）認為他將虛構的建築混入考古復原圖中，是對學術嚴謹性的嚴重違背。然而，現代建築理論家——特別是彼得·艾森曼（Peter Eisenman）和阿爾多·羅西（Aldo Rossi）——則將這幅平面圖視為建築思想史上的一次重大突破：它證明了建築可以作為一種純粹的智識活動存在於圖紙之上，不必受限於實際建造的可能性。這使得《古代羅馬的馬爾斯廣場》成為二十世紀「紙上建築」和「自主性建築」（autonomous architecture）理論的重要先驅。

## 收藏故事

《古代羅馬的馬爾斯廣場》出版後在學術界引起了爭議性的反應。考古學家們質疑其中虛構建築的比例，而建築師和藝術家們則被其非凡的想像力所折服。隨著時間的推移，這部著作的聲譽不斷攀升——特別是在二十世紀後半葉，當後現代主義建築理論家們重新發現皮拉內西時，《古代羅馬的馬爾斯廣場》被提升為西方建築思想史上最具革命性的文獻之一。
