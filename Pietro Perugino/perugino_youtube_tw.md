# Pietro Perugino — YouTube contents (繁體中文)

## A. Video Core Narrative

從佩魯吉諾與拉斐爾兩幅《聖母的婚禮》切入，影片讓觀眾先看老師自己的廣場、儀式和神殿。西斯汀《交付鑰匙》、佩魯賈坎比奧議事廳與晚期畫作，說明他如何用清晰空間、柔和色層和工作坊設計回應不同委託；「甜美」與「重複」都要回到作品逐件檢驗。

## D. Detailed Segment Plan

### Segment 1 — 誰教拉斐爾畫出這個廣場？

**Purpose:** 以師生同題作品開場，轉回佩魯吉諾。  
**Key Message:** 佩魯吉諾在拉斐爾成名之前，已建立可辨認的空間語言。  
**Content:** 先把米蘭布雷拉的拉斐爾《聖母的婚禮》放在右側，卡昂的佩魯吉諾版本放在左側。兩畫都有前景婚禮、寬闊廣場和遠處中央神殿；人物疏密與空間深度卻不同。先讓觀眾找共同的建築輪廓，再把鏡頭停在佩魯吉諾的敞開門洞。這位經常被稱為「拉斐爾的老師」的畫家，當時早已經營工作坊，承接教宗及城市公會的重要訂單。影片將從拉斐爾的熟悉形象退回老師自己的畫面，問：他如何讓一片空間顯得如此安穩？  
**Artwork / Person / Place Mentioned:** 佩魯吉諾、拉斐爾；兩幅《聖母的婚禮》；卡昂、米蘭

### Segment 2 — 從翁布里亞走向羅馬

**Purpose:** 交代早期證據與西斯汀工程。  
**Key Message:** 他的早期師承未定，1480年代的教宗委託卻有明確作品可看。  
**Content:** 佩魯吉諾本名彼得羅・瓦努奇，出生於翁布里亞奇塔德拉皮耶韋；約生於1450年，亦有約1448年的館方定年。早期訓練缺乏直接紀錄，與皮耶羅・德拉・弗朗切斯卡的師承只可說可能。約1470年他進入佛羅倫斯韋羅基奧的藝術圈，1472年有同業會紀錄。到1480至1482年，他參與西斯汀禮拜堂牆面工程，1481年10月另有具體合約。用西斯汀側牆的作品和日期卡建立場景，並標示其他畫家與助手共同工作，避免把整座禮拜堂都歸給他。  
**Artwork / Person / Place Mentioned:** 佩魯吉諾、韋羅基奧、皮耶羅；翁布里亞、佛羅倫斯、羅馬

### Segment 3 — 《交付鑰匙》：權威與透視

**Purpose:** 細讀西斯汀代表作。  
**Key Message:** 地面的線條把宗教儀式與建築秩序結合。  
**Content:** 基督將鑰匙交給跪著的彼得，這個前景動作象徵教會權威的傳承。沿鋪石線向後移，視線來到中央八角形神殿的開口；左右拱門則喚起羅馬君士坦丁凱旋門。遠處人物的尺度和前景相對，使廣場深度可感。先以全圖尋找鑰匙，再用簡單透視線疊圖指出消失方向，最後撤去標線：人物並沒有被幾何淹沒，透視反而讓儀式顯得穩定。中央建築是文藝復興畫家對耶路撒冷聖殿的想像，不是現存聖殿的實景紀錄。  
**Artwork / Person / Place Mentioned:** 《交付鑰匙》；基督、彼得；西斯汀禮拜堂

### Segment 4 — 城市裡的美德

**Purpose:** 解釋坎比奧議事廳的功能與圖像。  
**Key Message:** 宗教、古典德性與城市金融生活在同一房間相遇。  
**Content:** 從梵蒂岡轉到佩魯賈的坎比奧會所。約1496至1500年，佩魯吉諾為換錢商公會議事廳裝飾牆面：審慎、正義、剛毅、節制與古代哲人、統治者並置，另有降生、顯聖容、先知和西比拉。觀眾先看到整個房間，再逐個切到正義與節制，才理解這些形象出現在處理金錢與公會事務的地方有何意味。牆上還有畫家的自畫像與拉丁頌詞。資料對正式委託日期與整體施工期間劃分不同，影片採約1496至1500年的裝飾範圍，不把所有壁畫歸為同一年。  
**Artwork / Person / Place Mentioned:** 坎比奧議事廳、換錢商公會；佩魯賈

### Segment 5 — 甜美從何而來？

**Purpose:** 把風格形容詞還原為可見的畫面與技法。  
**Key Message:** 留白、柔和色層與可辨識的人物節奏造成沉靜感。  
**Content:** 再看《交付鑰匙》：前景人物之間保有空隙，儀式與遠景神殿也有廣場作緩衝。1495年的《哀悼基督》則以俯首和靠近遺體的姿態表現悲痛，遠山延長沉思。倫敦收藏的帕維亞修道院祭壇畫三板，館方具體說明白底上的薄色層、油彩緩乾和透明罩染如何使膚色與陰影柔和銜接。把三件作品並列，不要把倫敦三板的技術檢驗直接套用到每件佩魯吉諾畫作。「甜美」不是畫面沒有悲痛，而是人物、色層和空間讓情感以較舒緩的節奏到達觀眾。  
**Artwork / Person / Place Mentioned:** 《交付鑰匙》、《哀悼基督》、帕維亞祭壇畫三板

### Segment 6 — 兩幅《聖母的婚禮》

**Purpose:** 讓師生比較成為具體形式分析。  
**Key Message:** 拉斐爾借用了佩魯吉諾的框架，改變了人物與神殿的關係。  
**Content:** 佩魯吉諾的卡昂畫原為佩魯賈主教座堂聖戒指禮拜堂而作，約1500至1504年完成。前景祭司主持婚禮，約瑟持開花杖，失意求婚者折斷自己的杖；地面線條通往神殿敞開的門。拉斐爾1504年的米蘭版本採相近題材與中央建築，但人物站位、廣場的深度與人群到建築的距離重新調整。使用同步裁切逐一比較，不急著宣告哪一幅勝出。老師作品於1798年前後被法軍帶離佩魯賈，1804年撥交卡昂；兩畫如今相隔兩國，並排畫面是影片的比較工具。  
**Artwork / Person / Place Mentioned:** 佩魯吉諾、拉斐爾；卡昂與布雷拉《聖母的婚禮》

### Segment 7 — 聖徒、肖像與宮廷寓意

**Purpose:** 展示他不只畫一種面孔和一種題材。  
**Key Message:** 佩魯吉諾的宗教、肖像與宮廷畫有不同觀看目的。  
**Content:** 羅浮宮的《聖塞巴斯蒂安》以舒展身體和開放的建築背景呈現聖者，館方採1475至1500年的寬斷代；不要把常見的約1495年寫成唯一確定日期。1494年的《弗朗切斯科・德萊・奧佩雷肖像》把視線帶到具體人的臉與衣飾。再看伊莎貝拉・德斯特1503年委託、1505年完成的《愛與貞潔之戰》，畫家在曼托瓦書齋以神話人物處理寓意。三件畫逐一顯示，柔和姿態與清楚空間不是某一題材的固定模板；觀眾應問它們分別為哪種觀看場合而作。  
**Artwork / Person / Place Mentioned:** 《聖塞巴斯蒂安》、《德萊・奧佩雷肖像》、《愛與貞潔之戰》

### Segment 8 — 「重複」與仍在持續的委託

**Purpose:** 處理晚年聲譽、工作坊與後續工程。  
**Key Message:** 熟悉構圖的重用，須與每件作品的品質及委託分開看。  
**Content:** 瓦薩里記述，1507年佛羅倫斯領報大殿祭壇畫公開後，觀眾批評佩魯吉諾重複人物設計；這是後來傳記中的對答，不是可逐字還原的現場錄音。工作坊透過全尺寸稿重用構圖，確有實際製作的理由。1508年儒略二世又委託他畫梵蒂岡火災廳天頂，後來拉斐爾工作坊的教宗史壁畫與他的天頂在同一房間並存。最後切到1522至1523年未完成、今藏V&A的《基督降生》：與早期降生構圖的相似，讓我們討論傳播，而不是一筆判成「停滯」。  
**Artwork / Person / Place Mentioned:** 領報大殿、火災廳、V&A《基督降生》；瓦薩里

### Segment 9 — 重新看見佩魯吉諾

**Purpose:** 從作品回扣師生比較，提出觀看方法。  
**Key Message:** 他的秩序和沉靜是自己的藝術成就。  
**Content:** 1523年佩魯吉諾在豐蒂尼亞諾因瘟疫去世，確切日期不詳；他正在繪製的《基督降生》未完成。回到開場的兩幅婚禮畫，現在先把拉斐爾版本淡出，只留佩魯吉諾：從約瑟的杖沿人群走到神殿門洞，再停在廣場的留白。接著快速回顧西斯汀的鑰匙與佩魯賈的德性壁畫。觀眾下次遇見這位畫家，可以先問三件事：人物之間留下多少空間？地面和風景把目光帶去哪裡？這份安寧服務的是教堂、城市公會，還是私人祈禱？  
**Artwork / Person / Place Mentioned:** 佩魯吉諾、拉斐爾；卡昂、梵蒂岡、佩魯賈

## G. Fact-Checking Notes

- 出生約1450年，另有約1448年；早期訓練無直接紀錄，與皮耶羅的師承是假說。
- 西斯汀牆面工作約1480–1482年，1481年10月27日是現存合約日期；多位大師及助手合作。不要把後來米開朗基羅的天頂畫和《最後審判》混為同一次工程。
- 《交付鑰匙》的中央神殿是文藝復興想像；透視與權威的連結是有畫面和館方解說支撐的詮釋。
- 坎比奧議事廳裝飾約1496–1500年，正式委託節點與工程時間在來源中區分不同。
- 倫敦帕維亞祭壇畫技術資料只適用於那組畫板，不能推及每幅作品。
- 卡昂《聖母的婚禮》約1500–1504；拉斐爾作品1504。佩魯吉諾原畫被法軍帶往法國，兩者原始委託與現藏地不同。
- 羅浮宮《聖塞巴斯蒂安》官方採1475–1500年寬範圍；約1495是其他資料定年。
- 瓦薩里對1507年負評、宗教信仰與逐利的敘述須標示傳記立場；基吉1500年的稱讚限定畫家「親手作畫」時。
- 1523年在豐蒂尼亞諾因瘟疫去世，確切日期不詳；V&A《基督降生》未完成，1843年揭取並於1862年入藏。
