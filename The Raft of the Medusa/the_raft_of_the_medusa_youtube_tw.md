# 《梅杜莎之筏》｜YouTube 影片內容規劃（繁體中文）

## A. Video Core Narrative

1816 年，一艘法國軍艦擱淺，約一百五十人被留在臨時木筏上；傑利柯沒有畫救援完成，而畫人們剛看到遠方船影、尚不知道對方會不會回頭的一秒。這幅巨畫用屍體、攀升的身體和幾乎看不見的船，把政治失職轉化成觀眾必須親眼走過的距離。影片沿著畫面從死亡走向求救，最後再問：誰有資格成為歷史畫的主角？

## B. Recommended Video Titles

1. 《梅杜莎之筏》：那艘船為什麼小到幾乎看不見？

3. 從屍體到求救的手：讀懂《梅杜莎之筏》

## D. Detailed Segment Plan

### Segment 1 — 船就在那裡，為何仍然絕望？

**Purpose：** 用看不清的小船提出全片問題。  
**Key Message：** 畫面描繪的希望尚未得到回應。  
**Content：** 先只給觀眾海天交界的一個微小記號，讓人猜它是什麼；再快速拉回整幅高 4.91、寬 7.16 公尺的畫。船影前方，求救者揮舞布巾；近處卻有已經死去的人。1818–1819 年的傑利柯沒有把結局畫給我們看，而是把我們放在尚不能知道結局的位置。接下來每個段落，都沿著這段從木筏到船的距離追問：一場真實海難為何需要如此巨大的畫布？  
**Artwork / Person / Place Mentioned：** 傑利柯；《梅杜莎之筏》；羅浮宮。  
**Visual Assets：** IMG-001 全畫；IMG-001 地平線船影裁切；IMG-001 揮巾人物裁切。  
**Source Page URLs / Direct Image URLs / Rights：** 見 E 表 IMG-001；三個鏡頭從同一直接圖片製作，Commons 標記 Public Domain Mark。  
**Suggested Visual Sequence：** 船影 Detail Crop → Slow Zoom Out 揭露全畫 → Pan 到紅布 → 標題。

### Segment 2 — 一艘軍艦與被放棄的人

**Purpose：** 建立海難與責任背景。  
**Key Message：** 木筏的出現與殖民遠征、指揮失當及棄船決策相連。  
**Content：** 1816 年，前往塞內加爾殖民據點的梅杜莎號於 7 月 2 日在阿爾金淺灘擱淺；7 月 5 日開始棄船，約一百五十人登上臨時木筏。原擬拖曳木筏的小艇離去，筏上人被留在海上。7 月 17 日阿爾戈斯號發現十五名仍活著的人，其中五人獲救後不久死亡。畫面不是精確複製某天的天氣或每位乘員，而是將被遺棄的後果集中於同一塊木板。以文字時間線交代日期，讓原作承擔主要視覺。  
**Artwork / Person / Place Mentioned：** 梅杜莎號、阿爾戈斯號、阿爾金淺灘、塞內加爾；薩維尼、科雷亞爾。  
**Visual Assets：** IMG-001 木筏全景；IMG-001 擁擠木板裁切；IMG-001 船影裁切；1816 年 7 月 2／5／17 日文字時間線（剪輯製作，非外部圖片）。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001 見 E；時間線依羅浮宮館藏頁及[倖存者英譯本](https://www.gutenberg.org/cache/epub/11772/pg11772-images.html)製作，非下載圖像。  
**Suggested Visual Sequence：** 全畫 → 下緣木板 Pan → 日期文字疊加 → 船影 Detail Crop。

### Segment 3 — 畫家如何重建沒有親歷的災難

**Purpose：** 說明調查與構圖不是現場攝影。  
**Key Message：** 傑利柯把倖存者證詞、人物研究與草稿轉化為經過選擇的畫面。  
**Content：** 傑利柯沒有站在木筏上。他接觸倖存者，研究人物姿勢與木筏，反覆尋找足以承載災難的畫面。大都會藝術博物館的六個科雷亞爾與薩維尼習作，可以讓觀眾看見畫家如何先在紙上安排身體；羅浮宮的早期油畫草稿，則能與巨幅定稿比較船影大小。不要把素描中每個姿勢說成確定的歷史乘員，也不要把關於畫家工作室的戲劇性傳聞當成已證實的事。  
**Artwork / Person / Place Mentioned：** 傑利柯；科雷亞爾、薩維尼；大都會藝術博物館、羅浮宮。  
**Visual Assets：** IMG-002 六人物習作；IMG-003 早期油畫草稿；IMG-001 定稿；IMG-002 素描手勢裁切。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001–003 見 E。  
**Suggested Visual Sequence：** 素描 Slow Zoom → 草稿 Cross Dissolve → 定稿 Side-by-Side → 身體局部對位。

### Segment 4 — 他選擇救援尚未確定的一秒

**Purpose：** 解釋時間選擇如何製造懸念。  
**Key Message：** 遠方看見阿爾戈斯號不等於已經獲救。  
**Content：** 倖存者敘述曾望見船、發出信號，船卻一度消失；後來才真正靠近。傑利柯選的不是獲救後的擁抱，也不是最暴力的一幕，而是訊號正在送出、回應仍未知的瞬間。早期油畫草稿中的船較容易找到，定稿卻把它壓縮到地平線附近。畫中的陰沉海天亦有戲劇重組：倖存者記述 7 月 17 日早晨陽光出現、天空無雲。這種差別讓觀眾分清見證與藝術。  
**Artwork / Person / Place Mentioned：** 《梅杜莎之筏》定稿與早期草稿；阿爾戈斯號。  
**Visual Assets：** IMG-003 草稿全圖；IMG-003 船影裁切；IMG-001 定稿船影裁切；IMG-001 求救手勢裁切。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001、003 見 E；敘事對照[1818 年英譯本](https://www.gutenberg.org/cache/epub/11772/pg11772-images.html)。  
**Suggested Visual Sequence：** 草稿船影 → 定稿船影 Side-by-Side → 布巾 Detail Crop → 船影暫時淡出。

### Segment 5 — 從屍體爬向紅色布巾

**Purpose：** 教觀眾沿構圖閱讀。  
**Key Message：** 兩座金字塔把死亡與求救連在一起。  
**Content：** 視線先停在近處橫臥的身體與抱住年輕人的灰髮男子，再沿坐起、伸手、互相支撐的人向上，直到揮巾的頂點。另一座由桅桿、繩索和帆形成的金字塔，讓身體上升的方向與風浪的壓力相遇。別急著把灰髮男子與年輕人確定為某對史實父子；畫面首先以姿態呈現失去。緩慢的鏡頭路徑比密集的箭頭更能讓觀眾體會：希望離前景的死者有多遠。  
**Artwork / Person / Place Mentioned：** 傑利柯；《梅杜莎之筏》。  
**Visual Assets：** IMG-001 前景裁切；IMG-001 灰髮男子裁切；IMG-001 人體頂點裁切；IMG-001 桅帆裁切。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001 見 E；各裁切源自同一畫像。  
**Suggested Visual Sequence：** 左下 Detail Crop → 沿背與手臂 Pan Up → 桅帆疊線 → 全畫緩慢拉遠。

### Segment 6 — 最上方的人是誰？

**Purpose：** 將視覺中心放回殖民與種族背景。  
**Key Message：** 模特兒、歷史倖存者與畫中人物不能直接畫上等號。  
**Content：** 最上方揮布巾的黑人形象是整群人的求救中心。奧賽美術館指出，傑利柯使用來自海地的模特兒約瑟夫，並在定稿中增加黑人形象。倖存者名單另有一名黑人士兵讓・夏爾；這是歷史記錄，不足以證明畫中頂端人物就是他的肖像。以人物素描與定稿並置，說明畫家怎樣賦予這個人物行動力，也讓觀眾看見殖民遠征、奴隸制度與圖像階序之間的張力；廢奴意義屬於有依據的詮釋，不宜說成畫家親口宣告的唯一意圖。  
**Artwork / Person / Place Mentioned：** 約瑟夫、讓・夏爾、傑利柯；奧賽美術館、摩根圖書館。  
**Visual Assets：** IMG-001 揮巾人物裁切；IMG-004《黑人男子頭像》作品頁（圖片待確認）；IMG-001 群像裁切。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001、004 見 E；奧賽[展覽說明](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/black-models-gericault-matisse)。IMG-004 沒有已確認直接圖址，拍攝前確認授權與下載。  
**Suggested Visual Sequence：** 頂端 Detail Crop → 全群 Pan Down → IMG-004 作品頁參考或停留在 IMG-001 → 返回揮巾者。

### Segment 7 — 時事如何變成巨幅歷史畫

**Purpose：** 說明作品的政治與藝術尺度。  
**Key Message：** 無名受難者取得原本保留給英雄的歷史畫尺度。  
**Content：** 1819 年沙龍以《海難場景》展出的畫作，寬逾七公尺。古典人體的重量、劇場般的明暗與大畫布，通常能宣示英雄或國家榮耀；這裡卻承載政府失職後被放棄的人。畫作初掛高處，到 10 月底才移低，不能把今天羅浮宮貼近觀眾的展示方式直接投射回整段沙龍展期。作品在傑利柯生前沒有被王室收購，1824 年遺作拍賣才以 6,005 法郎進入皇家收藏。影片用畫面和少量文字量尺處理制度歷史。  
**Artwork / Person / Place Mentioned：** 傑利柯；1819 年沙龍、羅浮宮、福爾班。  
**Visual Assets：** IMG-001 全畫；IMG-001 前景身體裁切；IMG-001 揮巾者裁切；4.91 × 7.16 公尺文字量尺（剪輯製作）。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001 見 E；沙龍懸掛與交易資料見[羅浮宮館藏記錄](https://collections.louvre.fr/en/ark:/53355/cl010059199)。  
**Suggested Visual Sequence：** 全畫 + 尺寸文字 → 人體局部 Cross Dissolve → 沙龍／1824 文字時間線 → 全畫。

### Segment 8 — 再看一次那艘船

**Purpose：** 回答開場問題並留下一種觀看方法。  
**Key Message：** 畫面讓希望可見，卻不讓死亡因此消失。  
**Content：** 沿剛學會的路線再看：近處木板和屍體，抱住年輕人的男子，攀升的身體，揮起的布巾，最後是遠方的小船。這次不要停在希望的頂點；讓鏡頭沿相反方向回到已經無法回應的人。船之所以小，是因為結局尚不屬於木筏上的人。這幅畫把當代政治醜聞擴大到歷史畫的尺度，也讓今天的觀眾在巨大的身體面前感受到救援尚未抵達的時間。  
**Artwork / Person / Place Mentioned：** 傑利柯；《梅杜莎之筏》、羅浮宮。  
**Visual Assets：** IMG-001 前景裁切；IMG-001 揮巾者裁切；IMG-001 船影裁切；IMG-001 全畫。  
**Source Page URLs / Direct Image URLs / Rights：** IMG-001 見 E。  
**Suggested Visual Sequence：** 前景 → 顶端 → 船影 Slow Zoom → 回到前景 → 全畫淡出。

## G. Fact-Checking Notes

- 羅浮宮定稿資料：1818–1819、油彩畫布、491 × 716 公分、INV 4884／C 51；1819 年沙龍舊題為 *Scène de naufrage*。[館藏](https://collections.louvre.fr/en/ark:/53355/cl010059199)
- 約一百五十人上筏、十五人被發現時仍生還；其中五人獲救後死亡，不能把「十五名獲救」與「最終十人生還」混為一談。7 月 5 日至 17 日相隔十二天，含首尾計十三個曆日，影片用「近兩週」。
- 船先被看見又一度消失，及當天早晨晴朗，來自[倖存者早期英譯本](https://www.gutenberg.org/cache/epub/11772/pg11772-images.html)；畫中陰天是藝術重組。倖存者敘述有自身立場。
- 奧賽辨識模特兒約瑟夫；讓・夏爾見倖存者名單。兩者與畫中形象不可直接等同；廢奴解讀須標明為[奧賽的詮釋](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/black-models-gericault-matisse)。
- 羅浮宮記載沙龍初期掛得較高，到十月底才降低；今日展示位置和高度不等於 1819 年開幕時的條件。1824 年拍賣成交價 6,005 法郎，1826 年起在羅浮宮展出。[館藏流傳史](https://collections.louvre.fr/en/ark:/53355/cl010059199)
- 圖片權利依所列圖檔頁與館方聲明；Commons 的 Public Domain Mark 並非對所有司法管轄區的保證。IMG-004 未確認，勿直接投入影片。
